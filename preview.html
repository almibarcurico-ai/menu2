📋 Instrucciones para Aplicar

  1. Elige tu opción favorita de las 4 de arriba
  2. Renombra los archivos:
    Si elegiste la opción 4 (recomendada), en la carpeta icons/:
    • Renombra icon-192-best.png → icon-192.png
    • Renombra icon-512-best.png → icon-512.png
    • Renombra apple-touch-icon-best.png → apple-touch-icon.png
  3. Sube a GitHub: Sube toda la carpeta icons/ actualizada
  4. Limpia caché:
    • Android: Configuración → Apps → Chrome → Borrar caché
    • iPhone: Configuración → Safari → Borrar historial y datos
  5. Reinstala la app: Entra al sitio y vuelve a instalar
  6. ¡Listo! Ahora verás el ícono con el logo de Almíbar 🎉
