===========================================
📊 CONFIGURACIÓN GOOGLE SHEETS
===========================================

PASO 1: CREAR GOOGLE SHEET
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Ve a https://sheets.google.com
2. Crea una hoja nueva
3. Nómbrala "Reseñas Almíbar"
4. En la primera fila, agrega estos encabezados:

   A1: Fecha
   B1: Nombre
   C1: ⭐ General
   D1: 🍽️ Comida
   E1: 🍹 Tragos
   F1: 👨‍🍳 Atención
   G1: 🎵 Ambiente
   H1: 💰 Precio
   I1: 📊 Promedio
   J1: 🤝 Recomienda
   K1: ❤️ Qué Gustó
   L1: 💡 Mejoras
   M1: 💬 Comentarios


PASO 2: CREAR SCRIPT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. En tu Google Sheet, ve a: Extensiones → Apps Script
2. Borra todo el código que aparece
3. Copia y pega este código:

```javascript
function doPost(e) {
  try {
    // Obtener la hoja activa
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    
    // Parsear los datos recibidos
    var data = JSON.parse(e.postData.contents);
    
    // Preparar la fila con los datos
    var row = [
      data.fecha,
      data.nombre,
      data.calificaciones.general,
      data.calificaciones.comida,
      data.calificaciones.tragos,
      data.calificaciones.atencion,
      data.calificaciones.ambiente,
      data.calificaciones.precio,
      data.promedio,
      data.recomendaria,
      data.queGusto.join(', '),
      data.queMejorar,
      data.comentarios
    ];
    
    // Agregar la fila a la hoja
    sheet.appendRow(row);
    
    // Respuesta exitosa
    return ContentService
      .createTextOutput(JSON.stringify({
        'result': 'success',
        'message': 'Reseña guardada exitosamente'
      }))
      .setMimeType(ContentService.MimeType.JSON);
      
  } catch (error) {
    // Respuesta de error
    return ContentService
      .createTextOutput(JSON.stringify({
        'result': 'error',
        'error': error.toString()
      }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
```

4. Click en "Guardar proyecto" (💾)
5. Ponle nombre: "Reseñas Almíbar"


PASO 3: IMPLEMENTAR EL SCRIPT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Click en "Implementar" → "Nueva implementación"
2. En "Tipo", selecciona: ⚙️ → "Aplicación web"
3. Configuración:
   - Descripción: "API de Reseñas"
   - Ejecutar como: "Yo ([email protected])"
   - Quién tiene acceso: "Cualquier persona"
4. Click "Implementar"
5. Autoriza la app (puede pedir permisos)
6. COPIA LA URL que te da (algo como:)
   https://script.google.com/macros/s/AKfycbz.../exec


PASO 4: PEGAR LA URL EN EL CÓDIGO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Abre el archivo: resenas-con-sheets.html
2. Busca la línea 350 (aproximadamente):
   
   const GOOGLE_SHEETS_URL = 'TU_URL_AQUI';

3. Reemplaza 'TU_URL_AQUI' con la URL que copiaste:
   
   const GOOGLE_SHEETS_URL = 'https://script.google.com/macros/s/AKfycbz.../exec';

4. Guarda el archivo
5. Súbelo a GitHub Pages


PASO 5: PRUEBA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Ve a tu página de reseñas
2. Llena una reseña de prueba
3. Envía
4. Verifica que aparezca en tu Google Sheet
5. Verifica que llegue el WhatsApp

PASO 2: Agregar fórmulas
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Copia estas fórmulas en la hoja Dashboard:

A1: ESTADÍSTICAS ALMÍBAR
(en negrita, tamaño 18)

A3: Total de reseñas:
B3: =COUNTA(Hoja1!B:B)-1

A4: ⭐ Promedio General:
B4: =AVERAGE(Hoja1!I:I)&"/5"

A6: 🍽️ Comida:
B6: =AVERAGE(Hoja1!D:D)&"/5"

A7: 🍹 Tragos:
B7: =AVERAGE(Hoja1!E:E)&"/5"

A8: 👨‍🍳 Atención:
B8: =AVERAGE(Hoja1!F:F)&"/5"

A9: 🎵 Ambiente:
B9: =AVERAGE(Hoja1!G:G)&"/5"

A10: 💰 Precio:
B10: =AVERAGE(Hoja1!H:H)&"/5"

A12: % que recomienda:
B12: =COUNTIF(Hoja1!J:J,"Definitivamente sí")/COUNTA(Hoja1!J:J)*100&"%"

===========================================
🔧 SOLUCIÓN DE PROBLEMAS
===========================================

❌ "No se guarda en Google Sheets"
   → Verifica que la URL esté correcta
   → Verifica que el script esté implementado
   → Revisa que los permisos estén dados

❌ "Error 403 Forbidden"
   → En el script, cambia "Ejecutar como" a "Yo"
   → En "Quién tiene acceso" debe ser "Cualquier persona"

❌ "No aparecen los datos"
   → Verifica que los encabezados estén en la fila 1
   → Verifica que el nombre de la hoja sea correcto
