## 🎯 CÓMO FUNCIONA:

```
┌─────────────────┐
│ 🇪🇸 ES | 🇬🇧 EN │  ← Esquina superior derecha
```

- Click en **🇬🇧 EN** → Cambia a Inglés

## 🔧 CÓMO EXPANDIR A MÁS PÁGINAS:

Para agregar el selector a otras páginas (menú-cocina.html, etc.):

### **1. Agregar CSS del selector:**
```html
<style>
/* Language Selector */
.language-selector {
    position: fixed;
    top: 20px;
    right: 20px;
    z-index: 2000;
    /* ...resto del CSS */
}
</style>
```

### **2. Agregar HTML del selector:**
```html
<div class="language-selector">
    <button class="lang-btn active" data-lang="es" onclick="changeLanguage('es')">🇪🇸 ES</button>
    <button class="lang-btn" data-lang="en" onclick="changeLanguage('en')">🇬🇧 EN</button>
</div>
```

### **3. Importar el script:**
```html
<script src="i18n.js"></script>
```

### **4. Agregar atributo data-i18n a textos:**
```html
<div data-i18n="happy-hour">Happy Hour</div>
```

## 📝 AGREGAR NUEVAS TRADUCCIONES:

```javascript
    es: {

    en: {
        'nuevo-texto': 'Text in English'
    }
};
```
