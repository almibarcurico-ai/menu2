PARTE 2A: CONFIGURAR ESCRITURA DE RESEÑAS (10 min)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📄 INSTRUCCIONES: INSTRUCCIONES-GOOGLE-SHEETS.txt

PASOS:
1. Crea un Google Sheet llamado "Reseñas Almíbar"
2. Agrega los encabezados (están en el archivo)
3. Ve a Extensiones → Apps Script
4. Copia el código del archivo
5. IMPORTANTE: Cambia el email:
   var emailDestino = "tu-email@gmail.com";
   Por tu email real
6. Implementar → Nueva implementación → Web app
7. Quién tiene acceso: Cualquier persona
8. Copia la URL que te da
9. Actualiza resenas-con-sheets.html con esa URL

RESULTADO: 
✅ Clientes pueden dejar reseñas
✅ Se guardan en Google Sheets
✅ Recibes email cada vez que dejen una reseña


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PARTE 2B: CONFIGURAR LECTURA DE RESEÑAS (10 min)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📄 INSTRUCCIONES: SCRIPT-LEER-RESENAS.txt

PASOS:
1. En el MISMO Google Sheet de arriba
2. Ve a Apps Script (si cerraste, Extensiones → Apps Script)
3. Agrega el código de SCRIPT-LEER-RESENAS.txt
   (agregarlo al final, no borrar lo anterior)
4. Implementar → Nueva implementación → Web app
5. Copia la URL
6. Abre ver-resenas.html
7. Busca:
   const GOOGLE_SHEETS_URL = 'TU_URL_DE_LECTURA_AQUI';
   const USE_GOOGLE_SHEETS = false;
8. Cambia por:
   const GOOGLE_SHEETS_URL = 'https://script.google.com/macros/s/TU_URL_REAL/exec';
   const USE_GOOGLE_SHEETS = true;
9. Sube ver-resenas.html a GitHub

RESULTADO:
✅ La página ver-resenas.html muestra reseñas reales
✅ Se actualiza automáticamente
✅ Los clientes ven las reseñas de otros clientes

SOPORTE RÁPIDO
================================================================================

PROBLEMA: "El logo no aparece al instalar"
→ Verifica que subiste la carpeta icons/ completa a GitHub
→ Borra caché del navegador e reinstala

PROBLEMA: "No recibo email de reseñas"
→ Verifica que cambiaste el email en el código
→ Revisa tu carpeta de Spam
→ Verifica que autorizaste los permisos en Google

PROBLEMA: "Las reseñas no se actualizan"
→ Verifica que USE_GOOGLE_SHEETS = true
→ Verifica que la URL termine en /exec
→ Prueba la URL en el navegador directamente

PROBLEMA: "No recibo emails de cumpleaños"
→ Verifica que ejecutaste configurarRecordatorioAutomatico
→ Verifica que el activador aparece en el reloj ⏰
→ Verifica que cambiaste el email en el código
