# 🍹 ALMÍBAR BAR & RESTAURANT - MENÚ DIGITAL

Sitio web completo para Almíbar Bar & Restaurant en Curicó, Chile.

## 📋 Contenido del Sitio

### Páginas Incluidas:

1. **index.html** - Página principal con acceso a todos los menús
2. **menu-cocina.html** - Menú de comida (pizzas, tablas, sandwiches, etc.)
3. **menu-barra.html** - Menú de bebidas (cócteles, cervezas, tragos)
4. **club-amigos.html** - Formulario de inscripción al Club de Amigos ⭐
5. **reservas.html** - Sistema de reservas con beneficios por grupo ⭐ NUEVO
6. **resenas.html** - Formulario para dejar reseñas (solo WhatsApp) ⭐
7. **resenas-con-sheets.html** - Formulario que guarda en Google Sheets + WhatsApp ⭐
8. **ver-resenas.html** - Página pública para ver reseñas de clientes ⭐
9. **carrito.html** - Carrito de compras para pedidos por WhatsApp

## 🚀 Cómo Subir a GitHub Pages

1. Sube todos los archivos HTML al repositorio
2. Espera 1-2 minutos para que GitHub Pages actualice
3. ¡Listo!
